## ✂️ Sobre o projeto

Protótipo **Fase 1** do site da Leozin do Corte: um site institucional 100% front-end (sem back-end, sem banco de dados), criado para apresentar a identidade visual, os serviços e a estrutura completa da futura plataforma de agendamento.

A seção de **Agendamento** já está no layout, sinalizada como *"Em construção 🚧"* — pronta para receber, na Fase 2, o sistema completo de login, calendário e integração com o Google Calendar.
